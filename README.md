# 이번달 나의 급여 계산
## 1)근무 날짜 및 종류 체크
### ** 입력 안내 확인후 입력
- 근무 날짜 선택
- 일한 시간 입력
- 근무 형태  선택
- 시급 입력
### 입력 정보 오입력시 정확한 데이터 확인 불가

## 2)입력후 근무 기록 추가 버튼 클릭 
### ** 내회사 급여 명세서 탭 확인
- 입력한 내용이 급여명세서 표로 입력되었는지 확인

## 3) 급여명세표 이상 없을시 총급여 계산 버튼 클릭
### ** 클릭후 내용 확인
- 총 근무 시간 
- 받아야할 총 금액

## 4) 말일에 확인후 리셋
### **익월로 넘어갈때 클릭 
### ** 데이터 오기입시 전체 기록삭제 후 재입력
- 전체 기록 삭제
